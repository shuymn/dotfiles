# 見た目を出す前に

マーク、アイコン、画像、画面の案は、オーナーに見せる前に自分で描画して見る（使えるツールが無ければ、ヘッドレスブラウザでページを PNG にする）。見るのは次の点。

- **中心:** 形の外接矩形が、枠の中で上下左右に等しい余白を持つか。座標から計算して確かめる。そのうえで見た目の重心を合わせる（丸や三角は少しはみ出させ、重い側に寄って見えないようにする）。
- **文字との並び:** 文字の横に置くアイコンは、スクリーンショットの画素から、アイコンの外接矩形の中心と文字の高さの中心（アセンダーの上端からベースラインまで、ディセンダーを除く）を測って比べる。flex の `align-items: center` が揃えるのは行の箱で、文字の見た目ではない。「揃っている」と報告するのは、報告する者（サブエージェントも）が測ってからにする。サイズの違う文字どうしを並べたときは、ディセンダーの無い字（例: r、v、数字）の下端の画素行を比べてベースラインを確かめる。
- **縮小:** 16 px と 32 px に縮めて、形が潰れたり別の物に見えたりしないか。
- **連想:** 人の形、文字、排泄物など、意図しない物に見えないか。形だけでなく色との組み合わせで見る（茶色や黄土色の丸い塊は排泄物に見えやすい）。
- **文脈:** 使われる場の慣習に合っているか（例: 利用者が見慣れた同種のサービスのアイコンと並べて違和感がないか）。
